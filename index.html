Practice: Navigating Your Terminal Worksheet

Published as a static page so this repository is visible on GitHub Pages.

Instructions

You will use your terminal to complete a few tasks. For each task:

  1. Follow the instructions for the task carefully.
  2. Enter the requested command or output specified by the instructions into the provided space below.

1) Create a directory called group-challenge in your home directory.

Command entered:

mkdir group-challenge

2) Inside group-challenge, create subdirectories resources, projects, and backups.

Command entered:

cd group-challenge
mkdir resources
mkdir projects
mkdir backups

3) Navigate to the resources directory using a relative path.

Submitted command/output:

cd ../resources
~/home/group-challenge/resources

4) Inside resources, create two empty files: one.txt and two.txt.

Submitted command/output:

cd ../resources
touch one.txt
touch two.txt
one.txt
two.txt
..
.

5) Move two.txt from resources to backups and rename it to archived_two.txt.

Submitted command/output:

mv resources/two.txt backups/archived_two.txt
.
..
archived_two.txt

6) Delete one.txt from the projects directory.

Submitted command/output:

rm projects/one.txt
.
..

7) Use a single command to navigate to the backups directory from the projects directory using a relative path.

Command entered:

cd ../../backups
